# handoff — 같은 프로젝트 내 세션 인계 (동일 PC 한정)

## 저장 위치 (규약)

작업 디렉토리(`cwd`) 기준 상대경로:
```
.claude/handoff/pending/   ← 대기 중
.claude/handoff/done/      ← 완료
```
⚠ 예외 — `cwd`가 `~/.claude` 자체일 때는 `.claude/handoff/`가 아니라 `handoff/`(중첩 방지).

파일명: `YYYYMMDD-HHmm-{slug}.md`(생성 시각 기준 — 정렬하면 그대로 큐 순서가 된다). `slug`는 케밥케이스, 한글 가능.

내용은 프론트매터 없이 순수 마크다운:
```markdown
# {제목}

생성: {YYYY-MM-DD HH:mm}

{본문 — 배경·경로·판단기준까지, 기존에 `[프롬프트]` 코드블록에 쓰던 것과 동일한 분량}
```

## 생성 절차 (CLAUDE.md 규칙 10-b가 호출)

메인 대화가 규칙 10-b ⓑ 분기(실제로 세션이 끝나는 턴)에서 `` `[🆕 새 세션]` `` 항목을 확정하는 순간 이 스킬을 호출하고, 이 섹션을 따라 위 규약대로 Write로 파일을 만든다. `.claude/handoff/`가 그 프로젝트의 `.gitignore`에 없으면 이때 조용히 한 줄 추가한다(이미 무시 대상이면 건드리지 않음) — 개인 작업 큐가 실수로 커밋되는 걸 막기 위한 1회성 안전장치.

## 소비 절차 (`/handoff` 호출 시)

1. `.claude/handoff/pending/*.md`를 Glob으로 나열한 뒤 **반드시 파일명 문자열 기준으로 다시 정렬**한다 — `Glob`은 수정시각(mtime) 순으로 반환하지 파일명 순이 아니다(실측 확인: 물리적 쓰기 순서가 파일명의 논리적 시각과 어긋나면 큐가 뒤집힘). 파일명이 `YYYYMMDD-HHmm-`로 시작하므로 문자열 정렬 = 시간순 정렬이 된다.
2. **0건** — "대기 중인 핸드오프 없음"이라고만 답하고 끝. 다른 지시를 기다린다.
3. **1건 이상** — 가장 오래된 파일 하나를 Read하고, 그 내용을 지금 사용자가 방금 지시한 것처럼 이어서 진행한다. 대기가 더 있으면 시작 전에 한 줄만 언급: "그 외 대기 N건: {제목 나열}"(가장 오래된 것부터 자동 진행, 다른 걸 먼저 하고 싶으면 사용자가 그때 바꿔 말한다 — 매번 선택창을 띄우지 않는다).

## 완료 처리

전역 규칙 9/11-c 기준으로 그 항목이 "매듭지어졌다"고 판단되는 시점(다음 세션 상태 블록이 다시 발화하는 시점과 동일 기준):
- 파일 맨 위에 `완료: {YYYY-MM-DD HH:mm}` 한 줄 추가.
- `pending/`에서 `done/`으로 이동(Bash `mv`).
- 이후 보고는 평소 10-b 세션 상태 블록 형식을 그대로 따른다(이 스킬 전용 출력 형식 없음).
