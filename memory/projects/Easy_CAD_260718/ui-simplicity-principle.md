Easy CAD의 UI는 **최상단에 종류를 두지 않는다.** 상단 도구모음에는 «화살표» 같은 상위 도구
하나만 두고, 직선·곡선·직각 같은 *종류*는 캔버스에서 객체를 선택한 뒤 **플로팅 미니툴바의
하위목록**에서 고르게 한다(Lucid·FigJam 방식). 세부 조절값(예: 직각의 각짐 정도)은 그 종류를
골랐을 때만 노출한다.

**Why:** 사용자의 최상위 기준이 "심플·쉽고·직관적"이다 — "도구가 너저분하게 있으면 안 된다"
(2026-07-24 직접 발화). 이 프로젝트 자체가 "가벼운 CAD 대체"라 도구 수가 늘면 존재 이유가 깎인다.

**How to apply:** 새 변형·스타일을 추가할 때 상단 툴바에 버튼을 늘리지 말고 선택-후-컨텍스트
경로에 붙인다. 미니툴바 자체도 계속 통합 대상이다 — 색 스와치 5개는 나중에 버튼 1개로 합칠
예정이고, 그 밖에도 통합·정리할 것이 많다고 사용자가 예고했다. 기능을 붙일 자리를 고를 때
"상단에 하나 더" 대신 "이미 있는 컨텍스트 안 어디"를 먼저 찾는다. [[arrow-tool-unification]]
