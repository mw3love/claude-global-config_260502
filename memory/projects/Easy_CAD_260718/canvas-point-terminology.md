사용자가 "변중심에 있는 화살표되는점" 같은 장황한 묘사 대신 짧은 용어로 소통하고 싶다고
요청(2026-08-11). 아래 용어로 통일해서 쓸 것 — 코드의 실제 개념(core_shapes.py/
core_view.py)과 1:1로 매핑되므로 코드 얘기할 때도 그대로 쓰면 된다.

| 용어 | 코드 개념 | 언제 뜨나 | 모양 | 하는 일 |
|---|---|---|---|---|
| 큐닷 | qc-dot (`_qc_dot_rects`) | 선택된 도형, 4변 중심 | 채워진 원(파랑) | 클릭=선택, 드래그=화살표 뽑기 |
| 포트점 | hover-port (`_hover_port_at`, `_shape_ports`) | 미선택 도형에 호버, 4변 중심(이산) 또는 테두리 임의점(연속) | 빈 원(파랑 테두리) | 화살표 시작점 예고, 드래그하면 화살표 생성 |
| 리사이즈핸들 | box handle (`_box_handle_cursor`) | 선택된 도형, 모서리 4개+변 4개 | 작은 사각 | 모서리=자유 리사이즈, 변=단축 리사이즈 |
| 회전핸들 | rotate handle | 선택된 도형, 우상단 바깥 | 코랄색 점 | 드래그로 자유회전 |
| 자국핸들 | cut handle (`_cut_handle_rects`) | TRIM으로 잘린 자리(cut) 경계 | 마름모 | 드래그로 자국 경계 재조절 |
| 알약 | seg-pill (`_SEG_HANDLE_PX`) | 선택된 직교 화살표(sarrow), 세그먼트 중간 | 알약형(둥근 사각) | 드래그하면 그 구간 평행이동 |
| 끝점핸들 | endpoint handle | 선택된 화살표/선, 양 끝 | 파란 사각 | 드래그로 재부착·재라우팅 |
| 밴드핸들 | bend handle (`_bend_handle_at`) | 선택된 곡선 화살표, 중간 | 작은 점 | 드래그로 곡률 조절 |

큐닷과 포트점은 자리는 같고 "선택 여부"만 다르다(같은 4변 중심 개념의 선택/미선택 상태).
