"텔레그램 (수신) 테스트"처럼 애매한 문구로 시작하면 서로 다른 두 기능(양방향 채널 vs 매 응답마다 알림) 중 뭘 원하는지부터 왕복이 생긴다. 사용자가 "다음엔 어떻게 요청해야 헤매지 않냐"고 직접 물어봐서 정리함(2026-09-01).

**Why:** 이번 세션에서 ⓵ 애매한 초기 요청 → 의도 재확인 ⓶ 어느 봇을 쓸지 확인 ⓷ 토큰이 어디 있는지 몰라 재질문, 이렇게 세 번의 왕복이 생겼다. ⓶⓷은 사용자가 이미 갖고 있던 정보([[reference-telegram-bot-tokens]] 폴더)를 초기 요청에 안 넣어서 생긴 지연이었다 — 내가 몰라서가 아니라 정보가 대화에 없어서였다.

**How to apply:** 자동화/알림/봇 관련 요청을 받을 때: (1) 트리거+효과를 구체적으로 표현하도록 유도 — 예 "텔레그램 테스트" 대신 "매 응답 끝날 때마다 텔레그램으로 알려줘"처럼. (2) 자격증명이 필요해 보이면 "이미 갖고 있는 토큰/설정이 있는지, 어디 있는지"를 초반에 먼저 물어 [[reference-telegram-bot-tokens]] 같은 위치를 바로 확인한다.
