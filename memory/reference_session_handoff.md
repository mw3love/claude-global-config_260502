CLAUDE.md 규칙 10-b의 `` `[🆕 새 세션]` `` 핸드오프는 프롬프트를 `[프롬프트]` 라벨 + 코드블록으로 답에 보여주기만 한다. 복사는 사용자가 직접 `Ctrl+C`로 한다.

**히스토리**: 2026-08-07에 `~/.claude/session-handoff.ps1`로 클립보드 자동 복사(+한때 새 탭 자동 오픈까지)를 시도했으나, 같은 날 실사용해보니 그닥 쓸모가 없어 사용자가 직접 원복 요청. 스크립트 삭제, CLAUDE.md·README.md 모두 코드블록 제시 방식으로 되돌림. 새 탭 자동 오픈은 그보다 먼저 `wt.exe`가 엉뚱한 창을 여는 문제로 이미 제거된 바 있었다.

**교훈**: 이 종류의 "편의 자동화"는 실측 없이 도입하면 되돌리는 비용(코드+문서+메모리 3곳 동기화)이 든다 — 다음에 비슷한 제안이 나오면 먼저 시험적으로 며칠 써보게 하고 굳히는 편이 나을 수 있다.
