# PasteFlow — 설정창 디자인 기록

대상: `pasteflow/ui/settings_dialog.py` (PyQt6, 다크, 강조색 코랄 `#fab387`).
하네스: `tools/settings_bakeoff.py` — 실제 SettingsDialog + 후보 QSS 전환 바(숫자키), `--selfcheck <dir>`로 후보별 탭 캡처.
구현 제약: Qt QSS로 되는 것만(흐림·그림자 등 웹 전용 효과 불가).

## 확정

- **라운드1 (2026-09-25) — 코랄 사용 범위: A1 유지(현재 그대로).** 카드 제목·입력칸 호버·활성 탭 글자·체크·저장 버튼 모두 코랄.
  - 기각: A2(제목·호버 중립, 코랄은 입력 중·체크·탭 밑줄·저장만), A3(A2 + 저장 버튼도 중립).
  - ⚠ 범용 취향 「강조색은 의미 있는 상태에만」(Easy CAD·CIMON 확인됨)과 **반대 결과**. 이유는 사용자가 밝히지 않음(확인 필요).
    추정: 설정창은 항목이 적고 한 번에 한 카드씩 읽는 화면이라, 대량 반복 요소(CIMON 카드 수십 개)와 달리 코랄 제목이 신호 노이즈가 안 됨 — 「밀도 의존」 가능성. 다른 프로젝트에서 또 나오면 preferences.md의 해당 항목에 예외 조건으로 반영 검토.

- **라운드2 (2026-09-25) — 라벨 꾸밈: 콜론 제거 + 불릿 유지 + 소제목 아래 들여쓰기(16px, `_SUB_INDENT`).**
  - 후보: B1 `•  라벨:`(현재) / B2 `라벨:`(불릿 제거) / B3 `라벨`(둘 다 제거).
  - 결과는 **섞어서 새 안**: 콜론은 「확실히 지우는 게 좋다」(B3쪽), 불릿은 고민 끝에 유지.
    결정적 지적은 후보 밖에서 나왔다 — 「GIF가 더 상위인데 초당 프레임이 들여쓰기가 안 돼 있다」.
    불릿 자체보다 **위계가 안 보이는 것**이 문제였다 → 불릿은 두고 하위 줄만 들여쓰기.
  - 교훈: 장식(불릿) 축을 비교하다가 구조(위계) 결함이 드러났다. 다음 라운드는 장식 축보다
    「상하위가 눈에 보이나」를 먼저 점검할 것.

- **라운드3 (2026-09-25) — 딸린 옵션(체크박스) 위치: C3 같은 줄 채택.** `PrintScreen 키로도 실행`·`녹화에 마우스 커서 표시`를 부모 단축키 칸 오른쪽에(`_with_option`).
  - 기각: C0 부모와 같은 높이 별도 줄(현재) / C1 입력칸 아래 입력칸 열 맞춤(윈도우 설정식) / C2 라벨 아래 들여쓰기.
  - 라운드2의 「위계가 보이나」 교훈을 그대로 이어받은 축. 들여쓰기(C2)보다 「한 줄로 묶기」를 골랐다 — 줄 수가 줄어드는 쪽.

- **라운드4 (2026-09-25) — 내비게이션(뼈대): D2 왼쪽 목록 + 아이콘 채택.** 폭 150px, 선택=코랄 글자·아이콘+왼쪽 3px 코랄 막대, 비활성=회청 `#9aa0b0`, 호버=`#222` 배경.
  - 기각: D0 위쪽 탭(현재), D1 왼쪽 목록 글자만.
  - 레퍼런스: MS NavigationView 가이드(최상위 5~10개면 왼쪽, 적으면 위쪽 탭 권장) — 항목 4개라 **가이드와 반대로 골랐다.** PowerToys는 도구 수십 개라 왼쪽 목록.
  - 아이콘: Phosphor 듀오톤 `gear-six`/`clipboard-text`/`camera`/`sparkle` (0-c 기성 자산, 4/4 존재). 아이콘 있는 쪽(D2)을 고름 — preferences의 「옅은 면+진한 선 듀오톤 선호」와 일치.
  - ⚠ 뼈대 결정이므로 다시 열 때는 「뼈대 재검토」 절차(이 근거부터 인용).

- **라운드5 (2026-09-25) — 여백·밀도: E2 여유 채택.** 카드 사이 12px, 카드 안 줄 사이 8px, 카드 안쪽 34/16/16, 입력칸 안쪽 7px 10px.
  - 기각: E0 현재(6/4, 32/14/14, 5px 8px), E1 촘촘(4/2, 28/12/10).
  - 「절제·깔끔」 취향과 같은 방향 — 빽빽함보다 숨 쉴 공간. (설정창은 항목 수가 적어 여유를 줘도 스크롤이 안 생김.)
  - 같은 라운드에서 기능 쪽 결정도 나옴: 따로 떨어진 「경로 붙여넣기」 카드(한 번짜리)가 어색하다 → 기능 자체 제거(비교 중 화면 구조가 기능 과잉을 드러낸 사례).
