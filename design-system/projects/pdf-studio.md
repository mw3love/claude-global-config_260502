- **강조색 = 코랄.** 정확한 hex 미확정 — 라운드1~2 목업에서 잠정 `#da7756`(Claude/Anthropic

  톤 지정 없음). **코드 반영 시 실제 화면에서 육안 확인 후 최종 hex 확정할 것** — 지금 값은
  1차 추정.
- **강조색은 의미 있는 상태에만**: 활성 모드 아이콘, 체크박스 체크, 포커스(미리보기 대상)
  좌측 바, 삽입 캐럿. 배경·패널 같은 상시 노출 요소엔 안 씀([[preferences]]의 범용 원칙 재확인).
- **모드 전환 = 좌측 아이콘 레일**(A1). 읽기/주석/페이지 3버튼, 세로 배치.
- **페이지 구성 화면 = 좌측 세로 리스트(폭 가변, `QSplitter`) + 메인 캔버스 확대 미리보기.**
  메인영역 썸네일 그리드 방식은 폐기.
- **삽입 드롭존 = 캐럿**(얇은 선, 리스트에서는 가로 방향). `QListView` 기본 드롭 인디케이터.
- **다중선택 = 체크박스**(색/테두리 방식 아님 — 포커스 표시와 채널 분리 목적).
- **우클릭 메뉴 = 행 전체가 타겟**, 캐럿 선 자체가 타겟 아님(조준면 확대).

## 라운드별 기록

### 라운드1 (2026-09-08) — 모드 전환 4안 + 드롭존 3안

후보: A1 좌측 레일 / A2 상단 세그먼트 / A3 자동숨김 / A4 모드 폐지·패널토글,
B1 캐럿 / B2 간격벌어짐 / B3 하이라이트밴드.

- **A1 채택(A2·A3·A4 반려).** 코멘트 반복: "왼쪽으로 몰아 배치하는 게 좋음". Claude의
  라운드1 추천은 A2(추가 화면 점유 0)였으나 사용자가 다르게 판단 — 읽기 모드 상시 62px
  점유라는 트레이드오프는 감수하는 것으로 처리.
- **B1 채택(B2 애매, B3 반려·무코멘트).** "b1이 더 좋음".
- **탈락 이유 기록**: A4는 PRD §3-1 구조를 바꾸는 반대제안이라 별도 검토했으나, "모드가
  배타적이면 주석 보며 페이지 정리가 막힌다"는 우려가 실제 판정으로 이어지진 않음(A1이
  A4보다 그냥 더 선호됨 — 배타적 모드 자체는 문제 삼지 않았다는 뜻).
- **파생 요구**: A1 코멘트가 예상 못한 구조 변경을 요구함 — "페이지도 주석처럼 사이드패널
  세로 리스트로". 이게 라운드2의 시작점이 됨.

### 라운드2 (2026-09-08) — 페이지 구성 사이드 리스트 밀도 3안

후보: C1 큰 축소판·번호만 / C2 중간+라벨 / C3 초소형·고밀도. 셋 다 드래그 삽입 캐럿·
우클릭 메뉴·체크박스 다중선택이 실제 동작하는 라이브 CSS로 제작(게이트웨이 이미지 생성
안 씀 — 이 축은 인터랙션이 핵심이라 정지 이미지 가치가 낮다고 판단).

- **셋 다 "좋음"** → 하나를 고르는 대신 **"어차피 폭 조절되게 해야 한다"는 결론으로 수렴**
  (C2 코멘트: "썸네일 크게도 보고 작게도 볼 수 있음", C3 코멘트: "사용자 의도에 맞게
  가변적으로"). **베이크오프가 "후보 중 하나 확정"이 아니라 "고정값 자체가 틀린
  질문이었다"로 끝난 사례** — 축을 좁히다가 오히려 "이건 축이 아니라 설정 가능해야 할
  값"이라는 상위 결론에 도달함. design-bakeoff 스킬의 표준 수렴(하나 선택)과 다른
  패턴이라 기록해 둠 — 다음에 "N개 후보 다 좋다"는 판정이 나오면 "혹시 이거 가변으로
  가야 하는 거 아닌가"부터 의심해볼 것.
- **부수 질문 3건, Claude가 분석해 결정(재베이크오프 안 함)**:
  1. 다중선택 = 체크박스 유지 vs 테두리색 → **체크박스 유지**. 포커스 표시가 이미 색(코랄
     inset bar)을 쓰므로 선택도 색으로 가면 라운드1 B3에서 겪은 "강조 채널 겹침" 문제가
     재발. 채널을 형태(체크마크)로 분리.
  2. 회전 메뉴(90 CW/90 CCW/180, 3가지) 구성 → **평면 목록 3항목**. 서브메뉴·팝업은 클릭
     수를 늘림(§3 평가축과 충돌).
  3. "캐럿 선 자체에서 우클릭"이 폐지됐는지 질문 → **폐지 아님, 행 전체로 타겟 확대**.
     캐럿(3px)은 라운드1에서부터 "조준 정밀도 요구"가 약점으로 지적된 지점이라, 우클릭
     타겟을 행 전체(조준면 훨씬 넓음)로 옮긴 것은 축소가 아니라 그 약점의 개선.
